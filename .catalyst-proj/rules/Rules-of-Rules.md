# Rules-of-Rules

## Purpose

This document defines the rule framework for the `log-sump` project and how governance artifacts are organized.

## Scope

- Every requirement, bug, feature, and housekeeping item must trace back to a concrete rule or stated project need.
- Rules are stored in their own files and indexed from the rule set root.
- Changes must preserve traceability and be testable.
